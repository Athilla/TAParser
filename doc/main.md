#Terra-avantura parser

L'idée de l'application (cli) est de parser le site web terra-avantura.com (avec les identifiants de connexion) chaque parcours jusqu'a identifier un commentaires avec un QR-code exploitable. Quand on a trouver, on affichera le nom du parcours (la ville) et le code du QR-code et on le sauvegardera dans un fichier texte en y ajoutant le liens vers la bonne page du parcours avec le commentaire.
